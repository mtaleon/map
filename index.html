Custom Map

How to Play

Color every region on the map using 4 colors so that no two adjacent regions share the same color.

  • Select a color from the palette below the map
  • Click a region to fill it with that color
  • Gray regions are unfilled; shaded regions are pre-filled (given)
  • Red-highlighted regions have conflicts (same color as a neighbor)
  • On mobile: tap to select, tap again to place

Keyboard Shortcuts

  • 1-4 Select color
  • U / Z Undo
  • Y Redo
  • N New map
  • ? Hint
  • R Restart
