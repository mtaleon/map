Custom Map

How to Play

Use 4 colors to fill every region on the map, ensuring no adjacent regions share the same color.

Operating Instructions

  • Select a color from the palette below the map
  • Click a region to apply the selected color
  • Gray regions: not yet filled
  • Darker regions: pre-filled, cannot be changed
  • Red-highlighted regions: color conflicts with adjacent region, needs adjustment

Mobile Device Tips

  • First tap: select region
  • Second tap: place currently selected color

A Note on Approach

Take time to consider how regions relate to each other. Sometimes a different color arrangement makes the whole map suddenly clearer.
